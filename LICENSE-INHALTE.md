Need for Geschwindigkeit ist ein Spiel von ONE HUMANITY. Die MIT-Lizenz in [`LICENSE`](LICENSE) gilt für den Code;
was für welche Dateien gilt:

| Was | Lizenz |
|---|---|
| Code: Skripte (`scripts/`), Shader (`shaders/`), Szenen (`scenes/`), Werkzeuge (`tools/`), Projektdateien | [MIT](LICENSE) |
| Eigene Inhalte: Bilder, Grafiken, Screenshots, Texturen, Vinyls, Piktogramme, ausgedachte Plakate, Texte (`assets/`, `release/`, `update_bilder/`, die Dokumente) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.de) |

| Fremde Dateien: Motorklänge, Geräusche, Musik, Schriften | eigene Lizenzen, siehe [CREDITS.md](CREDITS.md) |
| Name und Herz-Logo von ONE HUMANITY, die drei echten ONE-HUMANITY-Plakate, das Wandbild | Kennzeichen von ONE HUMANITY, **nicht** frei lizenziert |

## CC BY 4.0 für die eigenen Inhalte

Du darfst die eigenen Inhalte teilen und bearbeiten, auch kommerziell, wenn du ONE HUMANITY als Urheber nennst, einen
Link zur Lizenz angibst und kenntlich machst, was du verändert hast. Vollständiger Lizenztext:
https://creativecommons.org/licenses/by/4.0/legalcode.de

Beispiel für die Namensnennung: „Grafik aus Need for Geschwindigkeit von ONE HUMANITY, CC BY 4.0“.

## ONE HUMANITY

Name und Logo liegen bei, damit das Spiel vollständig ist. Wer eine veränderte Fassung weitergibt, entfernt oder
ersetzt sie (Logo, Wandbild, die drei echten Plakate in `assets/posters/posters.png`, `tools/poster_icons/onehumanity_*`,
`release/itch_seite/onehumanity_*`), damit sie nicht wie eine offizielle Fassung aussieht.

werden; einzeln und unverändert weitergeben oder verkaufen darf man sie nach dieser Lizenz nicht.
